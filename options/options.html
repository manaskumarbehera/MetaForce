Keyboard shortcuts

Open / close MetaForce
Next tab (Search ⇄ All Data)
Previous tab

Click a shortcut, then press the keys you want (include Ctrl, Cmd, or Alt). Shortcuts work while a Salesforce page is focused. Combos the browser reserves — Ctrl/Cmd+T, W, N, Cmd+Q… — can't be overridden, so MetaForce won't let you pick them.

All Data tab

Adds a tab that lists every field of the record with label, API name, type, and value.

Double-click an updateable field to edit it and save changes back to Salesforce. Use with care — this writes to live records.
